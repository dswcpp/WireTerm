# Agent 自定义模型

WireTerm 的 OSS GUI 使用本机直连的 OpenAI Chat Completions 接口。

1. 打开设置中的 **Agent**，开启页面顶部开关。
2. 在 **Custom Models** 中添加 endpoint，填写名称、Base URL 和模型 ID。
3. 远端接口填写 API Key；本机 `localhost`、`127.0.0.1` 或 `::1` 的服务可以留空。
4. 保存后，在 Agent 模型选择器中选择该模型；没有有效的旧偏好时默认使用第一个自定义模型。

Base URL 例如 `https://provider.example/v1` 或 `http://localhost:11434/v1`。
应用会补上 `/chat/completions`，也接受包含完整路径的 URL。模型 ID 必须与服务实际提供的
名称相同，显示别名可以自行设置。远端地址要求 HTTPS，HTTP 仅允许回环地址。

API Key 保存在现有系统安全存储中，endpoint 和模型定义保存在本地设置中。发送消息时，
当前提示词、显式选中的文本/文本附件和该对话的文本历史会发送给选择的 endpoint。
直连请求不经 Warp 转发，不添加 Warp 账号请求头，不回退到 Warp 额度或云模型。

当前实现支持文本对话、流式回答，以及经用户确认的终端命令调用。模型可以请求当前终端执行
命令，应用展示原有命令卡片，用户确认后执行，并将输出或拒绝原因返回模型继续回答。
直连模式下命令必须人工确认，既有自动批准配置不会使这些命令自动运行。
尚不支持独立文件读取工具、图像输入、串口设备控制和云端编排。需要分析文件或设备日志时，
可以粘贴相关文本，也可批准模型提出的读取命令。
非文本附件会明确报错。长对话超过请求上限时，应新建对话并提供较小的文本片段。

每个用户请求最多开放 8 轮命令调用，每轮最多一个命令。输出按字符边界限制为 32 KB，
截断会明确标记。拒绝、取消、终端忙或命令转为长时间运行后，下一次模型回复不再开放命令
工具，需新的用户请求才能继续；运行中的命令仍使用原有终端停止/取消操作。
模型接口须支持 OpenAI Chat Completions 的 `tools` 和流式 `tool_calls`。

没有配置模型时不会自动访问默认模型服务。此页只描述 Agent 直连路径，不表示整个应用的
历史云服务依赖已经完成移除。

## 终端 `#` 命令建议

在终端输入开头键入 `#`，例如 `# 列出当前目录中的文件`，可使用命令搜索中的 Agent
翻译入口生成 Shell 命令建议。此入口使用 Agent 默认配置所选的自定义模型，向该 endpoint
发送这次查询及终端的 Shell/操作系统信息。生成的命令和描述显示在原有搜索结果列表中，
由用户选择、检查后执行，不由模型自动执行。普通终端命令仍交给原来的 Shell。

该入口要求 OpenAI Chat Completions 接口支持 `stream: false`，并按提示返回命令建议的
JSON 数组；不支持的模型或不完整的响应会显示错误。未配置模型时提示进入设置，
不回退到 Warp 接口，也不刷新 Warp 额度。已运行的旧进程需重新构建启动后才会加载修改。

本次 `#` 接入的主应用及测试代码严格 Clippy 检查通过（2m55s，零警告），随后完成定向
格式化。新增响应格式校验用例通过类型检查，未执行运行测试；真实模型和 GUI 端到端未验证。

### 后续回归修复（2026-11-08）

早期版本选择命令搜索的 Ask Agent 项时，未先进入 Agent 会话，导致输入模式切换被视图策略
拒绝，提示词可能留在 Shell 输入中。现改为先打开 Agent 会话，再填入并锁定 AI 提示词。
同时修复直连 HTTP 调用在非 Tokio 执行器上的运行时适配问题。

本轮实际运行结果：10 项直连接口测试、1 项命令搜索进入 Agent 会话的回归测试、2 项 `#`
触发设置测试均通过。覆盖本机 HTTP 模拟接口、流式中文、取消、重定向拒绝及命令建议请求。
这些结果替代上文相应用例“未执行”的历史状态；真实供应商和 GUI 端到端仍需单独验证。
